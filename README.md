# SUPER SNIPER 8D

**8x precision scope. 8D spatial audio. Feel every shot.**

A complete, playable premium sniper game for Unity — 3 missions, moving targets,
headshot scoring, a bolt-action rifle with 8x scope, breath-holding, a
**cinematic bullet cam**, impact VFX, procedural sound, mission dossiers, a
results screen, a pause menu, and mobile touch controls. The entire scene (city,
rooftop, first-person rifle, targets, HUD, audio, reticle) is **generated by
code**, so the project needs **zero downloaded assets** and **zero Inspector
wiring**. The scope reticle is aspect-correct on any screen ratio.

---

## Setup (5 minutes)

1. Install **Unity Hub**, then **Unity 6 LTS** (add the *Android Build Support*
   module during install — you'll want it later).
2. In Unity Hub: **New Project → Universal 3D (URP)** template. Name it
   `SuperSniper8D`. Open it.
3. Copy the `Assets/Scripts` folder from this repo into your project's
   `Assets/` folder (drag it into the Project window, or copy via file explorer
   while Unity is closed). Wait for scripts to compile — bottom-right spinner.
4. In the empty default scene: **GameObject → Create Empty**, name it
   `Bootstrap`, and in the Inspector click **Add Component → Game Bootstrap**.
5. Press **Play**. You're sniping.

That's the whole setup. One empty object, one component.

## The game

- **Mission 1 — Rooftop Overwatch** — 3 static targets, 60 seconds
- **Mission 2 — Market Drift** — 5 targets, 2 moving, 60 seconds
- **Mission 3 — Last Light** — 7 targets, 5 fast movers, 75 seconds
- Body shot = 50 pts, **headshot (amber sphere) = 150 pts**
- Each mission opens with a skippable **dossier brief**; clearing it shows a
  **results screen** with score, accuracy, headshots and best-shot distance.
- Run out of time → the mission fails and you can retry. Clear all three →
  campaign-complete screen.

## The Bullet Cam (signature feature)

On the **final kill of every mission** — or any **headshot past 200 m** — time
collapses to 0.15×, a dedicated camera detaches and chases the round along its
path with a slow roll, the world's sound drops to a whisper, and impact lands on
a single white frame before sound crashes back in. Skippable after the first
viewing (click / Space / tap). This is the shareable moment the whole design
hangs on; see `docs/SuperSniper8D_Design_Monetization.md`.

## Where the "8D" lives

- **8x scope** — `WeaponController.cs`: aiming lerps the camera FOV from 60°
  to 7.5° (60 ÷ 8) with a code-generated scope reticle overlay, sway, and
  breath-hold steadying (hold too long and your aim spikes).
- **8D audio** — `ProceduralAudio.cs`: every world sound is synthesised in code
  and played through 3D `AudioSource`s (`spatialBlend = 1`): looping wind beds
  placed around the map, positional hit "dings" at the target you struck, plus
  an in-head heartbeat that climbs while you hold your breath. Wear headphones.
  For full binaural HRTF, add the free **Steam Audio** plugin later and enable it
  as the spatializer in *Project Settings → Audio*.

```
├── Targets/Target.cs            ← takes hits, physics knockback, reports kills

```

## Troubleshooting

- **Errors mentioning `Input` or "InputSystem"** → *Edit → Project Settings →
  Player → Other Settings → Active Input Handling* → set to **Both** (or
  *Input Manager (Old)*). Restart the editor when prompted. (The scripts use the
  classic `UnityEngine.Input` API.)
- **Everything is pink/magenta** → you created a Built-in pipeline project
  instead of URP. It still works (the code falls back to the Standard shader) —
  but if it's pink, re-create the project with the **Universal 3D** template.
- **No text on screen** → very old Unity version missing `LegacyRuntime.ttf`.
  Use Unity 6 / 2022.2+.
- **Can't click a menu button** → the cursor unlocks automatically on menus; if
  it doesn't, press Esc.

## Building to Android (when ready)

1. *File → Build Settings → Android → Switch Platform*
2. *Player Settings*: set landscape orientation, company/product name,
   minimum API 24+
